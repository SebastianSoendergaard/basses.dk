Martin Fowler - Software Design in the 21st Century

Walkthrough of a number of refactoring patterns

Main takaways:
  • introduction of multiple patterns

Practical Refactoring - How to clean code in many small steps

Hands-on example on how to very quickly clean up and refactor messy code to clean and manageble code

Main takaways:
  • never be more than 2 minutes away from commit,
  • every refactor should bring better code so you can stop at any point in time
  • remove the 3 C's; Clutter, Complexity and Cleverness
  • remove all clutter, like comments, dead code ect. to make the actual code/patterns visible
  • remove all complexity, like bad names, long methods, nesting ect.
  • remove all cleverness, like cryptic or abbreviated code
